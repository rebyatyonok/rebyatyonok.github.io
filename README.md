# rebyatyonok.github.io

## Edit and publish

1. Edit `index.html`.
2. Open a terminal in this folder.
3. Run:

```sh
git add index.html
git commit -m "Update website"
git push
```

For the first publish, create a public GitHub repository named `rebyatyonok.github.io`, then run:

```sh
git add .
git commit -m "Create website"
git remote add origin git@github.com:rebyatyonok/rebyatyonok.github.io.git
git push -u origin main
```

The site will be available at <https://rebyatyonok.github.io>.
